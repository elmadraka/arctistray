# ArctisTray

A Windows system tray application that automatically switches audio devices when a SteelSeries Arctis 7+ wireless headset connects or disconnects.

## Status

Mandatory disclaimer AI was used for the development. Everything has been tested manually and seems to be working as intended.

Maybe your radio interface number or on report prefixes need adjustments for different devices.

Easy as opening it and it will switch to your headphones when switched on and return to your previous output when turned off (or the selected output in the system tray application)

Room for improvement
- Actually it uses ony Arctis 7+ default output and not any of the sonar virtual devices
- Input selection to allow also switching with the audio output and recover when turned off.
